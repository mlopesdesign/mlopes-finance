# Especificação funcional inicial

O MLopes Finance é um aplicativo Windows local-first. Cada instalação começa com contextos, contas e categorias editáveis pelo usuário.

O núcleo atual cobre o caminho mínimo de cadastro de contexto, conta, categoria e lançamento. Lançamentos usam valores inteiros em centavos, data `YYYY-MM-DD` e auditoria. Cartões avançados, investimentos detalhados, OFX/CSV, conciliação completa, comercial e relatórios serão adicionados em versões posteriores antes da primeira distribuição comercial.
